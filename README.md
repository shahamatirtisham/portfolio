# Pixel Portfolio

An original, playful top-down pixel-world portfolio for an engineering student. Visitors can explore the map with WASD or the arrow keys, select buildings, and use the standard navigation to read the portfolio directly.

## Personalize before publishing

The main profile information and starter project entries are grouped near the top of `app/page.tsx`. Replace every `YOUR NAME`, placeholder email, GitHub link, LinkedIn link, sample project, achievement, and research entry with the portfolio owner's real information. Add a profile photograph and project images when available.

## Technology

- TypeScript and React
- CSS-based pixel artwork and animation
- Vinext/Vite build
- Responsive keyboard, mouse, and touch interactions
