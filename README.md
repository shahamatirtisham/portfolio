# Md Shahamat Irtisham — Pixel Portfolio

A playful, top-down pixel-world portfolio for Md Shahamat Irtisham, a CSE undergraduate at the Islamic University of Technology. Visitors can explore the map with WASD or the arrow keys, click buildings, or use standard navigation.

## Technology

- React and TypeScript
- Vite static build
- CSS pixel artwork and animation
- Responsive keyboard, mouse, and touch interactions
- Automated GitHub Pages deployment

## Run locally

Requirements: Node.js 22.13 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Push this project to its `main` branch.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **GitHub Actions** as the source.
5. Open the **Actions** tab and wait for “Deploy portfolio to GitHub Pages” to finish.

The deployment automatically handles both project repositories such as `portfolio` and user-site repositories such as `shahamatirtisham.github.io`.
